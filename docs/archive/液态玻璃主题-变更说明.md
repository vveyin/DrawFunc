## 一、用户能看到什么

1. **设置页新增「主题」一行**（在"函数示例"下面）：点一下就在 `经典 ⇄ 液态玻璃` 之间循环切换，副标题直接显示当前主题名。切换**立即生效、全 App 换装**，且**不需要**重新走"切坐标系确认"那套流程。
2. **液态玻璃主题**（ColorOS 风格）由四层视觉构成，全部用绘制实现、**零新依赖、API 24 可用**：
   - **彩色氛围底**：深夜蓝竖向渐变 + 青 / 紫 / 粉 / 薄荷四团弥散径向光晕（替代原来的纯黑背景）；
   - **半透明玻璃体**：控件底色变成"带色相的半透明"斜向渐变（左上 34% → 右下 16%），像玻璃有厚度；
   - **顶部掠光**：玻璃面上方一层约 16% 的竖向白色渐变；
   - **高光描边**：1dp 边，上沿约 55% 白（受光面）→ 中段接近透明 → 下沿淡青色相折射光。
3. **按键也有玻璃色相分工**：普通键 = 冷蓝、选中/页签 = 青、危险键（⌫） = 玫红、浮层 = 深蓝。**选中渐染、左滑删除的渐染动画在玻璃模式下照旧演出**（色相层同步 lerp）。
4. **经典主题逐像素不变**：`AppSurface` 双路径，非玻璃模式下走的就是原来的 `Surface` 实色绘制，一个像素都没动。

真机调试入口：`ui/theme/LiquidGlass.kt` 里 `GlassPalette` 集中了全部视觉参数（光晕位置/浓度、玻璃透明度、描边浓度），`Modifier.liquidGlass` 的三层绘制也都在同一个文件。

## 二、怎么做到的（架构）

### 新增文件

| 文件 | 作用 |
|---|---|
| `ui/theme/LiquidGlass.kt` | 液态玻璃全部参数与绘制：`GlassPalette`、`LocalAppTheme`、`isLiquidGlass()`、`appGlassTint()`（经典实色 → 玻璃色相的**唯一翻译层**）、`Modifier.liquidGlass`（三层绘制）、`AppSurface`（主题感知表面）、`GlassBackdrop` / `AppBackdrop`（氛围底） |

### 主题与着色

- `Theme.kt`：新增 `enum class AppTheme { CLASSIC("经典"), LIQUID_GLASS("液态玻璃") }`；`FunctionDrawerTheme(theme = …)` 按主题选色板，并通过 `CompositionLocalProvider(LocalAppTheme provides theme)` 把主题传下去。
- `WatchColors.kt`：原来写死的角色色抽成 `interface AppRoleColors`，经典 `WatchPalette`（值一个没改）+ 玻璃 `GlassRoleColors`（深蓝底、surfaceContainer 阶梯、primary 青、网格线降亮度）两个实现；`activeRoleColors` 这个 **snapshot 状态**让普通 getter 的扩展属性也能在主题切换时重组——这是"约 50 处 `scheme.surfaceContainerHigh` 不用改一行"的关键。

### 三层持久化（存档兼容）

- `GraphState.kt`：`WatchSettings` 末尾追加 `val theme: AppTheme = AppTheme.CLASSIC`。
- `PlotMetrics.kt`（`SettingsFields`）：末尾追加第 11 段 `liquidGlass`，`FIELD_COUNT = 11`。**老存档缺这一段 → 经典主题**（升级上来的老用户观感逐像素不变）。
- `Store.kt`：save 写 `theme == LIQUID_GLASS`，load 按布尔恢复。

### 控件玻璃化（约 35 处 `Surface(` → `AppSurface(`）

覆盖：设置行、函数行/对象行/调色板、选中 chip、键盘（数学/字母/退格/长按气泡）、属性栏与数值 chip、滑条行与播放键、缩放栏、保存图片弹窗（卡片/输入框/两颗按键）、存档列表行、关于页、曲线信息卡与 toast 浮层。**渐染站点**（选中 chip、两处左滑删除渐染）除 `color` 外显式传 `glassTint`——在 `appGlassTint` 换算后的色相上再做 normal→danger/accent 的 lerp，玻璃模式下动画的色相过渡和经典模式一一对应。

`AppSurface` 的 modifier 语义与 `Surface` 一致（先画玻璃、调用方 modifier 叠后），所以 ripple / 按压缩放 / `graphicsLayer` 动画全部不受影响。
