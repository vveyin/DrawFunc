# f(x) · 手表函数图像绘制器

给 **Android 11 圆屏手表**（跑完整 Android，不是 Wear OS）写的开源函数绘图 App。
Material Design 3 观感，圆表盘自适应（同时兼容方屏 / 手机），手势 + 旋转表冠操作。

```
y = f(x)        显函数
r = f(θ)        极坐标
(x(t), y(t))    参数方程（列表里显示为「描点」）
F(x, y) = 0     隐函数（marching squares）
z = a + bi      复平面：数值运算 → 画点
```

包名 `com.functiondrawer.watch`，应用名「f(x)」，compileSdk 34 / targetSdk 34 / minSdk 24
（主目标设备是 Android 11 圆屏手表，Android 7.0 以上也能装）。

---

## 一、功能

### 绘图

- **四种曲线模式**：显函数、极坐标、参数方程、隐函数；另有三套坐标系
  （笛卡尔 / 极坐标 / 复平面）。切换坐标系时已有曲线会换算成新坐标系下最接近的模式。
- **隐函数**用网格 + marching squares，并对产生线段的单元递归细分（细分时重新求值），
  `x²+y²=1` 这类细线不会被网格粒度切碎。
- **参数/极坐标**先均匀取样、再按"屏幕上不够直"的区间递归二分，自交与旋转都正常。
- **断线判定**：显函数相邻样本跳变超过 2 倍屏高就断开，`1/x`、`tan(x)` 不会画出假竖线。
- 曲线颜色 / 线型 / 线径**实时生效**，改外观不触发重新采样。

### 函数与参数

- 列表里每行显示名称 + 表达式 + 模式；点行进入编辑器（自绘数学键盘，4 个页签：
  数字 / 初等 / 字母 / 其他，另有大写字母表键盘）。
- **自动命名**：函数 `a(x)`、`b(x)`…（小写）；方程与点 `A`、`B`…（大写），
  取第一个未占用的名字，用完 `z` 后进位成 `aa`。
- **滑动条**：表达式里出现不属于函数名/采样变量的单个字母时，确定后自动生成
  `-5~5`、步长 `0.1` 的滑动条；长按滑动条行可改名称 / 上下界 / 步长；支持往返播放。

### 几何工具（在图上画点、线、度量）

- 描点、直线、线段、射线、垂线、中垂线、平行线、角平分线、切线；
- 轴对称 / 中心对称 / 平移（可作用于点和曲线）；
- 角度、面积、距离度量；
- **吸附**：描点自动靠近原点、坐标轴、曲线，以及两曲线交点（优先级 原点 > 坐标轴 > 曲线），
  吸附来的特征点画成空心点；交点会随曲线变化实时跟随；
- 拖点的手感：在曲线上描的点**只能沿那条曲线移动**，不会突然跳到别的曲线上；
  由点派生的直线 / 曲线（含重启后）都会继续跟随。

### 交互

| 手势 / 输入 | 效果 |
|---|---|
| 单指拖动 | 平移（曲线与网格严格同步） |
| 双指捏合 | 以焦点为中心缩放 |
| 双击画布 | 复位视野到 `x ∈ [-10, 10]` |
| 单击曲线 | 选中并弹出信息卡（解析式 / 零点 / 顶点） |
| 单击对象 | 弹出点 / 线信息卡 |
| 旋转表冠 | 缩放（标准编码器、滚轮式、按键映射三条上报路径都接） |
| 方向键 / 音量键 | 上下缩放、左右平移 |
| 列表行左滑 | 删除该行（撤销走工具条箭头） |
| 第一屏左边缘右滑 | 进功能界面 |
| 图像界面底部上滑 | 拉出函数列表抽屉 |
| 长按底部提示条 1 秒 | 开始蓄力（阴影加深 + 中央蓝色进度条），进度走满进入截图界面 |

- 撤销 / 重做：快照栈（上限 20 步），拖滑动条的一次拖动合成一步；
  设置与视口刻意不进快照。
- 工具条上从一颗键滑到另一颗键可唤出撤销 / 重做（`⚙`↔`+` 或 `📁`↔`🗑`）。

### 截图与导出

- 长按提示条打开截图界面：预览当前画幅，可勾选**坐标轴 / 坐标数字 / 网格**（只影响这张图），
  输入文件名（右侧固定 `.png`），✗ 取消 / ✓ 保存。
- 图片自带不透明背景（白天白 / 夜间黑），画幅范围与图像界面完全一致。
- 保存位置：
  - 应用外部目录 `Android/data/com.functiondrawer.watch/files/Pictures`
  - 同时用 MediaStore 另存一份到 `Download/DrawFunc/`（无需存储权限，API 29+）
- 函数文件可导出 / 导入（`.fdf`，纯文本，函数 + 几何对象 + 制作说明都能往返）；
  列表右上角 `+` 也能调起系统文件选择器加载外部文件。

### 界面与设置

- **主题**：夜间（默认，黑底）/ 白天（白纸）；material / 液态玻璃两种风格，
  模糊背景可单独开关并调模糊程度；按钮投影强度可调。
- **显示项**：网格、坐标轴、坐标数字、示例列表；角度制 RAD / DEG；计算精度。
- **表冠**：模式与灵敏度可调，改完即时生效。
- **存档**：函数、滑动条、几何对象、吸附关系、设置、视口全部持久化，重启不丢。
- **新手教程**：从建函数、长按 sin、画曲线、截图、拉抽屉到工具使用，分步引导并可回退。
- 圆屏 / 方屏两套几何：宽度与位置按真实可用宽度（圆屏按弧宽）自适应，
  尺寸（行高、字号、圆点）按短边缩放。

## 二、表达式语法

支持省略乘号、右结合幂、绝对值、阶乘、Unicode 数学符号：

```
2x            隐式乘法
3sin(x)       = 3·sin(x)
(x+1)(x-1)    = x² − 1
2^3^2         512      （幂右结合）
-2^2          −4       （一元负号优先级低于幂）
|x|           绝对值
5!            阶乘（非整数走 Γ(n+1)）
2×3  6÷2      手写符号也能吃
```

函数：`sin cos tan cot sec csc`、`asin acos atan atan2`、`sinh cosh tanh coth`、
`asinh acosh atanh`、`exp ln lg lb log`、`sqrt cbrt root`、`abs sign`、
`floor ceil round trunc frac`、`gamma erf sinc`、`pow hypot mod min max clamp`、`deg rad`

常量：`pi π e tau τ phi φ inf ∞ nan`

约定：`log(x)` 以 10 为底（与 Desmos 一致），`log(b,x)` 以 b 为底，`ln` 是自然对数。
写错变量名会明确报错并列出可用变量。

复平面模式支持直接输入复数（如 `1+i`、`(2+3i)*(a-b)`），求值后画一个点并标注结果。

## 三、构建

前置：JDK 17、Android SDK（platform android-34、build-tools 34.0.0）、Gradle 8.7。

```bash
export JAVA_HOME=/path/to/jdk17
gradle -p . --no-daemon --console=plain :app:testReleaseUnitTest :app:assembleRelease
```

产物：`app/build/outputs/apk/release/f(x)-release.apk`。

签名密钥与口令在根目录 `keystore.properties`（已被 `.gitignore` 忽略，独立放在私有仓库）。
**如果要正式发布，请换一套自己的密钥。**

单元测试：`app/src/test/java/...` 共 634 个用例，覆盖引擎（表达式、视口、采样、几何、
复数、曲线变换、文件格式）与纯 Kotlin 的 UI 模型（键盘、工具状态机、文件名规则、版面几何）。

│   ├── MathFns.kt               函数与常量表，Γ / erf / 阶乘
│   ├── Viewport.kt              世界↔屏幕映射、缩放焦点保持、网格步长
│   ├── Plotter.kt               ★ 四种采样算法

│   ├── ComplexMath.kt           复数运算与复数表达式求值
│   └── CurveTransform.kt        函数的轴对称 / 中心对称 / 平移

    ├── MathKeyboard.kt          自绘数学键盘 + 表达式输入框
    ├── FunctionEditor.kt        编辑器：模式 / 表达式 / 范围 / 键盘

输出屏幕像素坐标，UI 只画线 —— 最需要正确性的部分能被纯 JVM 测试覆盖。

## 五、已知限制

- 隐函数靠网格发现零点，比网格还细的特征会被漏掉；提高精度档位可缓解，代价是求值次数上升。
- 参数方程的 t 范围只能选预设值，不能任意输入；极坐标默认范围 `0 ~ 2π`。
- 图片另存 `Download/DrawFunc` 走 MediaStore，只在 API 29+ 生效。
- 未实现函数值表格、积分、导数作图（切线工具会求导，但没有"画出导函数"的一键操作）。
